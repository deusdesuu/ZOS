# 1. Дан файл содержащий текст произвольной длины. Найти контрольную сумму текста, как сумму кодов символов по модулю 256. Реализовать два потока: первый для чтения содержимого файла буфер длиной m символов, второй – для расчета контрольной сум

## Глобальные переменные

<img width="318" height="178" alt="image" src="https://github.com/user-attachments/assets/1574d075-a57e-4d93-8ba2-cab6f4fe9cdc" />

- const int m - длина буфера
- HANDLE hMutex - мьютекс
- char buf - буфер для считывания файла
- int buf_len - текущее кол-во элементов в буфере
- buffer_free, data_ready - флаги состояния буфера
- finished - дошли до конца программы

## Производитель

<img width="368" height="448" alt="image" src="https://github.com/user-attachments/assets/834a8cb5-1af4-4d7a-8f0f-e26217d1bccf" />

- локально открываем файл для считывания
- ждем освобождения буфера вторым потоком
- захватываем мьютекс
- считываем файл в буфер, обновляем флаги
- освобождаем мьютекс
- если достигли конца файла, завершаем

## Потребитель

<img width="338" height="384" alt="image" src="https://github.com/user-attachments/assets/eec76411-45e8-494f-a7b2-bcfe9b14bb6d" />

- ждем освобождения буфера первым потоком
- если буфер пуст - завершаем
- захватываем мьютекс
- считаем сумму
- освобождаем мьютекс
